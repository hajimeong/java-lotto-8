# java-lotto-precourse

## 로또
`로또 구입 금액`을 입력받아서 구입 금액에 해당하는 만큼의 로또를 발행하고,
`당첨 번호`와 `보너스 번호`를 사용자로부터 입력받아 
사용자가 구매한 로또 번호와 당첨 번호를 비교해 `당첨 내역 및 수익률`을 출력하는 게임

### 구현 기능 목록
1. 로또 구매 금액 입력받음
   + 금액은 1,000원 단위로 떨어지지 않으면 예외처리
   + 숫자가 아닌 문자가 입력된 경우 예외처리
2. 로또 번호 생성 -> 랜덤
3. 로또 번호 저장 (구매한 로또 개수만큼)
4. 로또 당첨 번호 입력 받음 -> 쉼표 기준으로 구분
   - 쉼표 사이에 숫자가 없으면 예외처리
   - 숫자가 아닌 문자가 입력되면 예외처리
   - 중복된 숫자가 존재하는 경우 예외처리
   - 숫자가 6개 이상이거나 미만인 경우 예외처리
   - 입력된 숫자가 로또 번호 범위 (1~45)를 벗어난 경우 예외처리
5. 보너스 번호 입력받음 
   - 숫자가 아닌 문자 입력된 경우 예외처리
   - 로또 번호 범위를 벗어난 경우 예외처리
   - 로또 당첨 번호와 중복되는 숫자인 경우 예외처리
6. 로또 당첨 번호와 구매한 로또 번호 비교
7. 당첨 통계 계산
   ```
    3개 일치 (5,000원) - 1개
    4개 일치 (50,000원) - 0개
    5개 일치 (1,500,000원) - 0개
    5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
    6개 일치 (2,000,000,000원) - 0개
    ```
8. 수익률 계산:  소수점 둘째 자리에서 반올림

## 클래스별 기능 정리
### [domain]
#### 1. Lotto
- 한 장의 로또 번호 리스트를 보관하는 클래스
- 로또 생성 시 중복 및 로또 범위 검증
#### 2. Lottos
- 여러 장의 로또(객체)를 관리하는 클래스
#### 3. WinningLotto
- 당첨 번호와 보너스 번호 관리
- `Lotto`객체와 보너스 번호를 포함
- 구입한 로또들의 번호와 비교를 통해 당첨을 계산하는 데 사용
#### 4. LottoRank
- 등수 정보 관리
- `맞은 개수`, `보너스 일치 여부`, `상금`을 정의
- 매치 개수와 보너스 여부에 따른 등수 계산 메서드를 포함
#### 5. LottoResult
- 등수별 당첨 결과 통계
- 총 당첨금 합계 계산
- 수익률 계산

### [util]
#### validator
- `InputValidator`: 입력 형식 검증
  - 숫자 여부, 공백 여부, 쉼표 구분 검증
- `BonusNumberValidator`: 보너스 번호 검증
  - 당첨 번호와 중복 여부 검증
  - 로또 범위(1~45) 검증
- `PurchaseValidator`: 구매 금액 단위 검증
  - 1000원 단위 여부 검증
#### InputParser
- 입력 문자열을 정수, 정수 리스트로 변환

### [service]
#### LottoGenerator
- 로또 번호 랜덤 생성
- 금액에 맞는 수량만큼 로또 생성
- 구매 수량 조회

#### LottoResultCalculator
- 구매 로또와 당첨 로또를 비교해 `LottoResult` 생성
- 로또 매치 개수 계산
- 보너스 번호 일치 여부 확인

### [view]
#### InputView
- 사용자 입력 담당
- 구입 금액, 당첨 번호, 보너스 번호 입력
#### OutputView
- 출력 담당
- 로또 구매 개수 출력
- 구입한 로또 번호 리스트 출력
- 당첨 통계 출력 : 등수별 당첨 개수, 총 수익률

### [controller]
#### LottoController
- 프로그램 전체 흐름 제어
- 로직
  - 구입 금액 입력 및 검증
  - 로또 생성
  - 생성된 로또 출력
  - 당첨 번호 입력 및 검증
  - 보너스 번호 입력 및 검증
  - 당첨 번호와 보너스 번호에 따른 당첨 결과 계산
  - 당첨 결과 출력
- 오류 발생 시 오류 메시지 출력 및 재입력
