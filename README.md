# java-lotto-precourse

## 로또
`로또 구입 금액`을 입력받아서 구입 금액에 해당하는 만큼의 로또를 발행하고,
`당첨 번호`와 `보너스 번호`를 사용자로부터 입력받아 
사용자가 구매한 로또 번호와 당첨 번호를 비교해 `당첨 내역 및 수익률`을 출력하는 게임

### 구현 기능 목록
1. 로또 구매 금액 입력받음
   + 금액은 1,000원 단위로 떨어지지 않으면 예외처리
   + 숫자가 아닌 문자가 입력된 경우 예외처리
2. 로또 번호 생성 -> 랜덤
3. 로또 번호 저장 (구매한 로또 개수만큼)
4. 로또 당첨 번호 입력 받음 -> 쉼표 기준으로 구분
   - 쉼표 사이에 숫자가 없으면 예외처리
   - 숫자가 아닌 문자가 입력되면 예외처리
   - 중복된 숫자가 존재하는 경우 예외처리
   - 숫자가 6개 이상이거나 미만인 경우 예외처리
   - 입력된 숫자가 로또 번호 범위 (1~45)를 벗어난 경우 예외처리
5. 보너스 번호 입력받음 
   - 숫자가 아닌 문자 입력된 경우 예외처리
   - 로또 번호 범위를 벗어난 경우 예외처리
   - 로또 당첨 번호와 중복되는 숫자인 경우 예외처리
6. 로또 당첨 번호와 구매한 로또 번호 비교
7. 당첨 통계 계산
   ```
    3개 일치 (5,000원) - 1개
    4개 일치 (50,000원) - 0개
    5개 일치 (1,500,000원) - 0개
    5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
    6개 일치 (2,000,000,000원) - 0개
    ```
8. 수익률 계산:  소수점 둘째 자리에서 반올림
